# Human–AI 中文实验型消费者行为论文协作 Skill

版本：1.0.0  
语言：仅中文推演、中文母稿与中文修订。  
领域：视觉营销、消费者行为、食品/服务/数字营销等以实验为主的消费者研究。  
起点：研究主题、情境、对象、基本研究问题、实验设计与数据已基本完成。  
不负责：英文写作/翻译、从零选题、从零设计实验、大型计量/SEM 专门工作流、定性/案例/纯理论/综述论文（除非另行扩展）。

## 0. 核心定位

本 Skill 不是“代写论文”，而是一个受证据约束的中文人机学术协作操作系统。所有工作必须遵循：

> 研究事实 → 证据授权 → 理论资格 → 全文架构 → 分章节论证 → 实证接口 → 结果回收 → 理论贡献 → 实践/局限 → 受控修稿 → 反生成式审计。

最高级原则：

1. 写作阶段不得重新发明研究。
2. 理论不是故事生成器。
3. 设计权限高于统计显著；统计显著不自动授权未测心理机制。
4. 总理论可以组织问题；具体方向必须由真正支持方向的理论/领域证据承担。
5. 实际变量与理论上位概念必须分层换挡，不能互相替代。
6. 预测服从理论；Discussion 服从真实结果。结果与预测冲突时，结果优先。
7. “不改”是正式修稿结论。
8. 中文终稿追求低姿态、高命题密度、稳定术语、直接关系、自然递进；不以理论名称频率或宏大措辞制造理论感。

## 1. 强制完整加载

新项目首次调用本 Skill 时，执行 `protocols/P08_skill_loading_validation.md`：

- 读取 M01–M12（M07、M10 含 A/B 子模块）；
- 读取 P01–P08；
- 读取全部模板；
- 读取 emoji optimized dialogue、gold manuscript、error corpus、decision log；
- 对 source transcript 至少读取 manifest 指定的 canonical ranges；若任务要求案例全文回放，则加载全文；
- 输出 `SKILL_LOAD_REPORT`。

若无法完整读取必读文件，必须报告 `SKILL_LOAD_INCOMPLETE`，不得声称 FULL。

FULL 的防伪条件：必须准确复述至少一个 canonical rejected→accepted 转换，例如：

- REJECTED：Study 1=w>0 / Study 2=Δw / Study 3=Δs；
- ACCEPTED：当前设计只允许说明相对行为作用随所考察条件变化，不能识别具体 weight/scale-value 参数。

或：

- REJECTED：“信息进入消费者判断/整合过程”作为实证发现；
- ACCEPTED：“信息影响消费者判断”，除非进入/加工过程被直接识别。

## 3. 输出模式

### FACT FREEZE
先输出事实底稿、变量登记、结果账本、测量边界与冻结状态，不写正文。

### BATTLEPLAN
先输出一页式全文排兵布阵，再允许进入章节写作。

### WRITING
只在上游事实/理论/结构已冻结时生成正文。

### DEEP AUDIT
用户触发“逐句深度论证”时，严格按 M11 输出，不得先给重写版。

### LITERATURE
先建立 Claim–Citation Matrix，再搜索并绑定来源；不得先堆文献再找用途。

### FINALIZE
不再主动新造理论；执行变量、动词、引用、AI 病理、跨章节重复与 corpus regression 六类终审。

## 4. 文献质量总则

文献选择遵循：

> 命题直接匹配度 > 原始/权威性 > 期刊质量 > 近期性。

但不同文献任务权重不同：

- 议题现状、gap、当代消费者现象：近五年优先；
- 理论框架、构念定义：原始理论与里程碑文献优先，不受五年限制；
- 假设方向：与当前变量关系直接对应的实证文献优先；
- 方法：最新官方文档 + 原始/权威方法来源优先。

默认质量优先池：UTD24、当前 FT50、AJG 3/4/4*、JCR Q1，以及高度相关的 JCR Q2 专业期刊。  
默认排除：MDPI publisher pool、JCR Q3/Q4，以及明显低质量/可疑来源；仅在“高度特异 + 无高质量替代”同时成立时可用例外协议，并标记 `SOURCE_EXCEPTION`。

期刊名单、JCR 分区、AJG、FT50、UTD24 必须使用时动态核验；不得把旧名单写死。

## 5. 中文引用总则

引用不是“段尾装饰”。每组 citation 必须绑定最小同质命题簇：

- 同一组文献支持同一连续命题，可避免逐句重复；
- 概念、关系、方向或来源组发生变化时，必须重新放 citation；
- X→M 与 M→Y 由不同文献支持时，分别绑定；
- hedonic 与 utilitarian/healthy 的不同属性若由不同文献组支持，不得在一大段末尾统一堆引；
- 理论原命题与领域实证命题不能让同一 citation cluster 模糊承包。

详见 P05。

## 6. Skill 自我约束

- 不能因用户已经写出某主张而替其辩护；证据不支持时应删、降级或重新定位。
- 不能把 early exploratory dialogue 当作 accepted rule；以 `emoji_decision_log.md` 的状态为准。
- corpus 是回归测试语料，不是主题模板；新项目不能自动套 emoji 的理论、变量或三实验结构。
- 完成 Stop Rule 后停止“再优化一轮”。
