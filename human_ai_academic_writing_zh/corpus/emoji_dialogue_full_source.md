[6] 我查了 Anderson 的经典 IIT 文献、functional measurement 路线，以及消费者/食品领域中实际采用 IIT 的已发表研究。这里的 IIT 指你文中采用的 Information Integration Theory（信息整合理论），不是意识研究里的 Integrated Information Theory。
[7] 结论先说
[8] 不需要因为使用 IIT，就额外用量表分别测“价值（scale value）”和“权重（weight）”。
[9] 更准确地说：
[10] IIT 理论上区分 value 和 weight；但实证研究是否必须把二者单独测出来，取决于你声称自己在检验 IIT 的哪一层。
[11] 而且还有一个很重要的点：经典 IIT 中的 value 和 weight 本来就不主要是靠“请被试报告价值/重要性”的量表来测的，而是通过 functional measurement 的因子设计和总体判断模式来推断/估计。 2021 年一篇专门讨论 IIT 在消费者研究中应用的论文对此说得非常明确：IIT 与普通多属性模型不同，它让参与者对多个信息组合后的整体刺激作判断，然后从 factorial response pattern 中恢复 functional values；只有在模型条件满足时，才进一步区分 scale value 和 weight。
[12] 所以，对你的论文来说，真正的问题不是：
[13] “我要不要再加两个量表测 value 和 weight？”
[14] 而是：
[15] “我要不要声称我的实验识别了 value 和 weight？”
[16] 这两个问题完全不同。
[18] 1. IIT 中的 value 和 weight 到底是什么？
[19] Anderson 的 IIT 把一条进入判断的信息区分为两个方面：
[20] information contribution∼wi​si​
[21] 其中：
[22] si​：scale value / subjective value，即这个信息在当前判断维度上“指向什么程度”。例如某一线索在“好—坏”“吸引—不吸引”“愿意回购—不愿意回购”维度上的心理位置。
[23] wi​：weight / importance，即判断时该条信息获得了多大的心理重要性/贡献程度。
[24] Norman 1976 年的经典实证研究就直接以 Weight and value in an information integration model 为题，通过实验设计估计不同信息的 subjective scale 和 importance weights。
[25] 后续研究同样明确指出，二者在 IIT 中概念上不同，但一般情况下并不能天然从一个简单效应里分离出来。研究者需要满足特定设计与模型识别条件才能把 weight 和 scale value 分开。
[26] 这点对你非常重要。
[27] 假如你发现：
[28] 食品表征型 emoji 在享乐食品中比情绪型 emoji 更能提高回购意愿。
[29] 单凭这个结果，不能知道究竟是：
[30] wrepresentational​>wemotional​
[31] 还是：
[32] srepresentational​>semotional​
[33] 或者两者同时发生。
[34] 普通 ANOVA 的主效应/交互效应无法自动把这两个心理参数拆开。
[36] 2. 已发表的 IIT 研究是不是都“测了” value 和 weight？
[37] 不是。
[38] 我检索下来，可以把使用 IIT 的论文大致分成两种。
[39] A. “严格 functional measurement 型 IIT”
[40] 这种论文的研究问题本身就是：
[41] 人究竟按照 addition、averaging、multiplication 中哪种 cognitive algebra 整合信息？
[42] 或者：
[43] 各条信息的 scale value 和 weight 分别是多少？
[44] 这种情况下，作者一般会使用完整 factorial design、single-information/subdesign 等设计，通过 overall judgment 的模式检验 cognitive algebra，然后估计 parameters。
[45] 例如 Norman (1976) 专门设计实验，使 subjective values 和 weights 可以分别估计。
[46] Hastak 和 Hong (1991) 在消费者产品质量判断中采用 functional measurement methodology，检验原产国 × 价格的整合，结果支持 constant-weight averaging model，并进一步得出 country image 和 price 的 derived scale values。
[47] 2021 年消费者研究中，让被试评价 3 个品牌 × 3 个价格的组合，并加入品牌单独呈现条件，通过 factorial plots 和 repeated-measures ANOVA 判断 averaging pattern，随后讨论/估计 weight 与 scale values。
[48] 食品领域也是如此。Booth 与 Conner 的 Food Quality and Preference 论文关注不同 sensory/conceptual influences 如何共同决定 food acceptability，其方法本身就是分析不同 influence 对选择的作用及其组合规则。
[49] 这时候：
[50] value/weight 是研究对象的一部分。
[51] 如果你的论文声称自己属于这一类，那么确实不能只做一个普通 2×2 ANOVA，然后说：
[52] “IIT 证明了消费者重新赋予了权重。”
[53] 证据是不够的。
[55] B. “IIT 作为 judgment/information-integration 理论框架”
[56] 另一类论文借 IIT 解释：
[57] 消费者不是孤立处理一条线索，而是在具体情境中整合多个信息来源形成整体评价。
[58] 此时研究重点未必是识别具体 cognitive algebra，也不一定单独估计 w 和 s。
[59] 例如 Smith (1993) 在 Journal of Marketing Research 中明确使用 Information Integration Theory 来研究消费者如何整合 advertising 和 product trial 信息，但其核心实验操纵的是 information source、sequence 和 trial favorability，理论目标是研究这些信息如何共同影响消费者评价，并不是要求每一个研究都加入一个独立“weight scale”和一个“value scale”。
[60] 类似地，消费者判断、陪审判断等研究也把 IIT 用于解释不同信息源如何共同影响最终 judgment，而研究重点可以放在整合模式、信息效应和情境依赖性上。
[61] 所以：
[62] “采用 IIT”≠“必须直接测 weight + value”。
[64] 3. 还有一个容易搞反的问题：IIT 其实不特别鼓励“直接问 weight”
[65] 这个地方我建议你特别注意。
[66] 如果所谓“测权重”是另外给一个问卷：
[67] “这个 emoji 对你有多重要？”1 = 完全不重要，7 = 非常重要
[68] 这甚至不一定是最符合 Anderson IIT 的做法。
[69] IIT 的 functional measurement 思路反而强调：
[70] 从人在组合信息条件下产生的整体判断中反推出信息的 functional value / importance。
[71] 而不是预设参与者可以准确内省并报告自己的认知参数。2021 年的消费者 IIT 论文明确把这一点和传统 multiattribute analysis 区分开来：传统做法往往直接评价各属性的 value/weight，而 IIT 关注组合刺激后的整体响应及整合运算本身。
[72] 早期消费者研究甚至比较过直接 elicited importance 与模型参数估计，发现二者会有差异，指出被试未必能准确报告其判断过程中的这些细节参数。
[73] 所以如果导师问你：
[74] “用了 IIT，为什么没有测权重？”
[75] 一个非常关键的回答是：
[76] IIT 的 weight 是 functional importance parameter，不等同于一个自陈的“重要性量表”。

[135] 8. 对你这篇论文，我会建议把 IIT 定位在这里

[137] 不是：

[140] “本研究估计 emoji information 的 value 与 weight。”

[159] Consensus
[160] 适合，但不能把 IIT 放得太重。以你现在的三个实验，我认为最稳妥的定位是：

[169] 而是下面三个问题。
[170] 1. “你说是 IIT，为什么没有做 functional measurement？”
[171] 这是最大的潜在问题。
[172] 严格的 Anderson IIT 不只是“多个信息一起影响判断”。它有完整的 valuation → integration → response 结构，并发展出 functional measurement，用 factorial response patterns 检验 adding、averaging、multiplication 等 cognitive algebra；更严格的研究还会估计 functional values 和 weights。2021 年一篇专门讨论 IIT 在消费者研究中使用的论文就把这看作 IIT 方法上的核心特色。
[173] 而经典研究确实会用特殊实验设计分别估计 subjective values 和 importance weights。
[174] 你的实验不是这种设计。
[175] 所以如果你写：
[176] 本研究基于 IIT 检验消费者如何对 emoji 赋予不同权重和价值。
[177] 那我认为会被质疑，而且质疑是合理的。
[178] 但如果你写：
[179] IIT suggests that judgments arise from the integration of multiple informational inputs; therefore, the contribution of a focal cue to an overall judgment can depend on the informational context in which it is encountered.
[180] 风险小很多。
[181] 因为消费者研究里确实存在这种更宽的理论应用。例如 Smith 在 Journal of Marketing Research 使用 IIT 研究广告信息和产品试用信息如何共同影响消费者判断，其设计也是操纵信息来源、顺序和试用正负性，而不是简单要求被试报告每条信息的 weight/value。
[182] 换句话说：
[183] 你可以采用 IIT 的“information integration principle”，但不要声称自己采用了完整的 functional measurement methodology。
[185] 2. “IIT 能不能推出你的具体假设？”
[186] 这里是第二个风险，而且我认为比 value/weight 更值得你注意。
[187] IIT 只能很好地解释“为什么发生交互”，但不能单独告诉你“交互往哪个方向发生”。
[188] 例如实验二：
[189] 为什么享乐食品中，食品表征型 emoji 应该比情绪型 emoji 更有效？

[192] 享乐型食品突出感官享受；
[193] 健康型食品突出健康/营养；
[194] representational imagery 对 indulgent food 的作用；
[195] taste/pleasure language 对 healthy food 的作用。
[196] 你现在已经在用 Ketron、Malik、Turnwald & Crum 等文献完成这一步。
[197] 所以正确的理论分工应该是：
[198] IIT

[200] 为什么 Emoji effect 是 context-dependent
[201] 而领域文献解释：
[202] 在什么 context 下，哪种 emoji 更有效
[203] 这两个不能倒过来。
[204] 实验三也是一样。
[205] IIT 可以解释：
[206] emoji 不应孤立处理，它和同时出现的文字信息共同进入总体判断。

[567] 1. 这篇文章研究什么
[568] 文章发表于《心理学与营销》（Psychology & Marketing），题目是《非预期试用对态度与行为的溢出效应：通过使用权型服务推广新产品》（Spillover effects from unintended trials on attitude and behavior: Promoting new products through access-based services）。研究背景是汽车共享等使用权型服务：消费者原本只是使用服务，但在这个过程中会无意中实际体验某个品牌的产品。作者把这种体验称为“非预期试用”。

[570] 消费者本来没有打算试用一个产品，但因为使用某种服务而接触并体验了它，这个新的体验信息会不会进一步改变消费者对产品和品牌的态度、购买意愿以及口碑？

[574] 2. 他们怎么理解 IIT

[2234] 外卖小票中的食品相关表情符号与回购意愿：食品类别与文字沟通框架的调节作用
[2235] 摘要
[2236] 外卖服务的普及使消费者在完成食品购买后、实际食用前仍会接触食品相关服务信息。小票作为仍与具体订单保持对应、但不直接参与食品呈现的服务信息载体，其中的食品相关视觉信息能否进一步影响消费者对已购食品的回购意愿，仍缺乏充分认识。本研究基于食品接受情境影响框架与信息整合理论，通过三项在线实验（N1=159，N2=128，N3=128）考察外卖小票中食品相关表情符号对回购意愿的影响。结果表明，相较于低语义视觉线索，食品相关表情符号产生了更高的回购意愿。食品类别调节两类食品相关表情符号的相对作用，享乐型食品（如炸鸡）中食品表征型表情符号产生更高的回购意愿，健康型食品（如沙拉）中情绪型表情符号产生更高的回购意愿。文字沟通框架同样产生调节作用，表达式文字下情绪型表情符号产生更高的回购意愿，而断言式文字下两类表情符号无显著差异。上述结果将食品外部视觉线索研究拓展至外卖小票中的回购判断，并表明食品类别与文字沟通框架构成其作用的重要情境边界，同时为外卖小票视觉设计与食品营销沟通提供理论参考与实践指导。
[2237] 关键词：外卖小票；食品相关表情符号；回购意愿；食品类别；文字沟通框架
[2238] 1 引言
[2239] 外卖服务的发展改变了消费者从食品选择到实际消费的接触流程，使一次食品消费由传统餐饮中相对集中的现场接触，延伸为跨越下单、交易、配送和实际食用的多阶段过程（Seo & Roh, 2025; Zhang & Ha, 2024）。随着接触阶段的增加，消费者面对的食品外部线索也由包装、标签、容器和餐具等直接参与食品呈现的信息，进一步扩展至食品外送服务流程中出现、但不直接参与食品呈现的其他信息（Motoki et al., 2023; Piqueras-Fiszman & Spence, 2015; Seo & Roh, 2025）。前一类线索已被广泛证明能够影响食品的感官预期、评价与选择，而近期研究进一步表明，食品外送服务过程中的信息与服务经历能够延续至消费者后续的回购判断（Kuo et al., 2025; Lin et al., 2024）。在食品与餐饮服务中，回购意愿是衡量既有顾客能否持续购买的重要结果变量，并与顾客留存和长期顾客价值密切相关（Gupta et al., 2004; Wang & Tsai, 2019）。回购意愿以既有购买为前提，指消费者未来再次购买同一产品或服务的意向性判断（Hellier et al., 2003; Mittal & Kamakura, 2001）。
[2240] 外卖服务将食品购买与实际品尝在时间上分隔，使消费者在购买完成、实际食用前仍可能接触食品相关服务信息（Lin et al., 2024; Zhang & Ha, 2024）。现有食品视觉研究更多聚焦购买前或与食品呈现直接相关的线索，对这一购买后阶段关注相对有限（Motoki et al., 2023; Piqueras-Fiszman & Spence, 2015）。
[2241] 外卖小票位于这一购买后阶段，并与当次订单保持对应。作为购买记录，小票记录已经发生的食品购买（French et al., 2008）；与包装、标签等直接参与食品信息呈现的外部线索不同，小票本身不参与食品呈现，却可以继续承载与当次购买有关的信息（Bedard & Kuhn, 2015; Piqueras-Fiszman & Spence, 2015）。已有现场研究进一步表明，小票中的个性化食品建议能够影响消费者下一次购买（Bedard & Kuhn, 2015）。
[2242] 作为消费者与品牌沟通中广泛使用的文本副语言，表情符号能够以图形形式补充甚至替代文字，并传递对象、语义和情绪信息，由此成为具有广泛营销应用基础的视觉沟通形式（Almaguer et al., 2025; Luangrath et al., 2017）。更重要的是，表情符号的视觉意义能够直接与食品建立联系。已有食品研究表明，表情符号能够通过对象指向、消费体验和情绪评价等不同信息功能与食品形成明确的意义联系，并被消费者用于表达和理解食品相关体验（Cao et al., 2024; Jaeger, Lee, et al., 2017; Jaeger, Vidal, et al., 2017; Vidal et al., 2016）。
[2243] 已有研究表明，账单、支付和外卖小票中的表情符号能够影响消费者反应，且其作用受食品与沟通情境影响（Lefebvre et al., 2024; Luo et al., 2026; Wang et al., 2023）。不过，现有证据尚未充分说明，在购买完成、实际食用前，小票中的食品相关视觉信息能否进入消费者对已购食品的未来重复选择。
[2244] Rozin和Tuorila（1993）的食品接受情境影响框架与Anderson（1981, 2013）的信息整合理论为解释这一问题提供了互补的理论基础。前者界定影响食品判断的时间性与同时性情境，后者进一步解释相关信息如何在具体判断情境中共同形成总体反应。基于这一理论结构，实验一检验小票中的食品相关视觉信息能否影响消费者对已购食品的回购判断；实验二和实验三分别**围绕同时性情境中的目标食品与伴随沟通信息，**检验食品类别与文字沟通框架的调节作用。
[2245] 基于上述研究结构，本文主要形成三方面贡献。第一，本文将食品外部视觉线索研究推进至购买后小票中的回购判断。第二，本文进一步比较不同类型食品相关表情符号对回购意愿的相对作用，并界定其食品与沟通情境边界。第三，本文结合食品接受情境影响框架与信息整合理论，将购买后的时间位置、目标食品与伴随沟通信息纳入同一解释结构，从具体判断情境理解购买后食品相关视觉信息的回购作用。
[2246] 2.1 理论背景
[2247] 食品接受受到判断发生时各种情境条件的共同影响。Rozin和Tuorila（1993）的食品接受情境影响框架将这些影响区分为同时性与时间性情境，其中同时性情境涵盖目标食品及其伴随的食品与非食品信息，时间性情境则涉及判断发生前后不同阶段的信息与经验。**沿此框架，购买后的时间位置构成本研究的时间性情境位置，目标食品与目标食品之外的伴随沟通信息则构成同时性情境的两个具体方面。信息整合理论进一步从判断形成过程说明，个体会对进入判断的相关信息进行评价和整合，并形成统一的总体反应（Anderson, 1981, 2013）。**这一整合视角也被用于食品接受研究，用以解释不同食品信息和影响因素如何共同作用于消费者的选择与接受判断（Booth & Conner, 1990）。由此，焦点信息对总体判断的作用需要结合其所指向的对象及共同出现的相关信息理解。
[2248] 基于这一理论结构，本研究首先考察小票中的食品相关视觉信息能否影响消费者对已购食品的回购判断，随后分别考察目标食品类别与伴随文字沟通框架如何改变两类食品相关视觉信息的相对回购作用。
[2249] 2.2 小票中的表情符号与回购意愿
[2250] 既有研究表明，产品与服务评价能够影响回购意愿，服务回应中的表情符号也会进一步影响重新购买意向（Ma & Wang, 2021; Mittal et al., 1998）。
[2251] 小票中的新增视觉线索能否进一步影响这种回购判断，与其是否提供食品相关信息密切相关。数字沟通研究表明，表情符号能够以视觉形式补充文字信息，并传递对象语义、情绪评价及相关情境意义（Luangrath et al., 2017; Riordan, 2017）。食品研究进一步表明，表情符号能够与具体食品、基本味觉、食品享用体验及其引发的情绪评价建立系统的意义联系，并被消费者用于表达和识别食品相关体验（Jaeger, Lee, et al., 2017; Jaeger, Vidal, et al., 2017; Reis Rocha et al., 2024）。
[2252] 根据表情符号所承载的信息功能，本文进一步区分两类食品相关表情符号。食品表征型表情符号指直接表征具体食品对象的语义型或非面部表情符号，情绪型表情符号指主要传递食品享用情绪和积极体验评价的面部或情绪型表情符号（Cao et al., 2024; Jaeger et al., 2021; Riordan, 2017）。食品表征型和情绪型表情符号虽然承载不同性质的内容，二者均能够向消费者提供与目标食品判断直接相关的信息，由此共同构成具有明确食品相关意义的视觉线索。相比之下，低语义视觉线索缺少与目标食品对象、食品享用体验或食品评价之间的明确意义联系。
[2253] 食品相关表情符号能够以对象或体验意义指向目标食品；当其出现在与订单对应的小票中时，这种食品关联可以进一步进入对已购食品的回购判断。相比之下，低语义视觉线索缺少明确食品关联，因此预期食品相关表情符号产生更高的回购意愿。据此提出以下假设。
[2254] H1：相较于低语义视觉线索，小票中具有明确食品相关意义的表情符号将提高消费者对已购食品的回购意愿。
[2255] 2.3 食品类别情境的调节作用
[2256] 已有食品视觉研究表明，同一外部视觉线索对食品判断的作用会随目标食品及其判断情境发生变化（Motoki et al., 2023）。食品消费者研究通常区分享乐型食品与健康型食品，两类食品分别突出不同的主要评价属性。享乐型食品更加突出味觉、感官愉悦和即时享受，健康型食品则更加突出健康、营养及长期收益（Ketron et al., 2021; Muñoz-Vilches et al., 2019）。营养诉求、味觉信息等相同类型的外部线索在不同食品类别中也表现出不同的评价与购买效应（Choi et al., 2012; Choi & Springston, 2014）。食品接受情境影响框架将目标食品本身纳入同时性情境，信息整合理论则说明焦点外部信息的作用需要结合当前判断对象及其他相关信息理解（Anderson, 1981, 2013; Booth & Conner, 1990; Rozin & Tuorila, 1993）。享乐型食品与健康型食品突出不同的评价属性，由此形成不同的目标食品情境，使随后出现的食品相关视觉信息连接到不同的评价内容。
[2257] 食品表征型与情绪型表情符号分别突出具体食品对象信息与积极食品享用评价，因此两类视觉信息的相对作用可能随目标食品所突出的评价属性而变化（Cao et al., 2024; Jaeger et al., 2021; Riordan, 2017）。
[2258] 对享乐型食品而言，具体食品线索能够引发针对目标食品本身的特异性欲望和消费反应（Fedoroff et al., 2003）。突出呈现享乐型食品形象本身能够强化消费者对其美味程度的判断，并进一步增强积极的消费反应（Malik et al., 2022）。因此，食品表征型表情符号所提供的具体食品对象信息与享乐型食品突出的味觉与感官评价联系更直接，预期在享乐型食品中产生更高的回购意愿。
[2259] 对健康型食品而言，具体食品形象所具有的购买优势明显弱于享乐型食品（Ketron et al., 2021）。健康型食品本身具有较为突出的健康和长期收益属性，而积极感官和享乐信息能够增强消费者对健康食品的享乐预期（Yang et al., 2026）。已有研究发现，以美味和满足为中心的信息能够提高蔬菜、沙拉及其他健康食品的即时选择，并维持较长时期的持续购买（Turnwald et al., 2019; Turnwald & Crum, 2019）。因此，情绪型表情符号所传递的积极食品享用评价能够补充健康型食品已有的健康意义，预期在健康型食品中产生更高的回购意愿。
[2260] 综合来看，食品类别应改变两类表情符号对回购意愿的相对效应。据此提出以下假设。
[2261] H2：食品类别调节表情符号类型对消费者回购意愿的影响。对于享乐型食品，食品表征型表情符号将比情绪型表情符号产生更高的回购意愿；对于健康型食品，情绪型表情符号将比食品表征型表情符号产生更高的回购意愿。
[2262] 2.4 文字沟通框架的调节作用
[2263] 表情符号的消费者效应会受到伴随文字的约束。既有研究表明，表情符号是否与文字共同出现以及其对文字内容的重申或替代会改变消费者的信息评价与说服反应，不同类型表情符号的相对作用也会随伴随文字内容而变化（Almaguer et al., 2025; Maiberger et al., 2024; Wang et al., 2023）。因此，表情符号类型的作用需要结合其所在的文字沟通框架理解。
[2264] 依据言语行为理论，断言式文字主要陈述产品事实与属性信息，表达式文字主要传递体验、态度和主观评价（Huang & Liu, 2022; Searle, 1979; Villarroel Ordenes et al., 2019）。在本研究的小票中，伴随文字属于目标食品之外的同时性沟通信息，并与表情符号共同指向已经购买的具体食品（Rozin & Tuorila, 1993）；按照信息整合理论，两类相关信息可共同参与消费者对该食品的总体判断（Anderson, 1981, 2013）。由此，文字框架所突出的信息内容可能改变两类表情符号在回购判断中的相对作用。
[2265] 在断言式文字中，食品事实与属性构成主要信息内容，食品表征型与情绪型表情符号分别提供食品对象信息和积极食品享用评价，两类视觉信息由此与文字形成不同的信息关系。当文字转向表达式框架时，消费体验和主观评价成为沟通重点。已有研究发现，在体验性内容中，情绪型表情符号相较于语义型表情符号能够产生更高的消费者反应；当面部表情符号重申文字已经表达的评价时，其说服效果也更高（Maiberger et al., 2024; Wang et al., 2023）。**情绪型表情符号所传递的积极食品享用评价在内容上直接对应表达式文字的沟通重点，而食品表征型表情符号主要继续提供食品对象信息，与表达式文字所突出体验评价的直接对应相对较弱。**因此，相较于断言式文字，表达式文字应使两类表情符号之间的回购意愿差异进一步有利于情绪型表情符号。据此提出以下假设。
[2266] H3：文字沟通框架调节表情符号类型对消费者回购意愿的影响。相较于断言式文字情境，表达式文字情境下两类表情符号之间的回购意愿差异将进一步有利于情绪型表情符号。
[2267] 5.1 一般性讨论
[2268] 三项实验表明，购买完成、实际食用前外卖小票中的食品相关视觉信息能够影响消费者对已购食品的未来重复选择判断，且其作用会随食品类别与文字沟通框架而变化。
[2269] 实验一表明，相较于低语义视觉线索，小票中具有明确食品意义的表情符号产生了更高的回购意愿，将购买后小票信息能够影响后续食品选择的既有证据进一步扩展至食品相关视觉沟通（Bedard & Kuhn, 2015）。
[2270] 实验二进一步表明，两类食品相关表情符号的相对作用具有明显的食品类别差异。食品表征型表情符号在炸鸡情境中的优势与具体食品表征能够增强享乐型食品积极评价的既有发现相一致（Malik et al., 2022）。相反，在沙拉情境中，情绪型表情符号表现出更高的回购意愿，这与积极享乐信息能够提升健康食品愉悦预期和选择反应的既有证据一致（Turnwald & Crum, 2019; Yang et al., 2026）。总体而言，食品类别使两类表情符号的相对回购优势发生反转，表明其相对效应并不存在跨食品类别的稳定模式，而受到目标食品类别的约束。
[2271] 实验三进一步表明，文字沟通框架改变了两类表情符号对回购意愿的相对作用，表达式文字下情绪型表情符号产生更高的回购意愿，而断言式文字下两类表情符号无显著差异。这一结果与体验性内容中情绪型表情符号具有相对优势，以及面部表情符号重申文字评价时说服效果更高的既有发现一致（Maiberger et al., 2024; Wang et al., 2023）。**从伴随文字与视觉信息的内容关系看，**表达式文字突出消费后的满足体验，情绪型表情符号同样指向积极食品享用评价，而食品表征型表情符号主要指向食品对象。在断言式文字情境中，两类表情符号分别指向食品对象信息和积极食品享用评价，当前结果未显示其中一类具有稳定的相对回购优势。
[2272] 5.2 理论贡献
[2273] 本研究首先扩展了食品外部视觉线索研究的时间位置、信息载体与结果范围。既有研究主要聚焦购买前或食品呈现相关的视觉线索，本研究则表明，食品相关视觉信息在购买后小票中仍能够影响消费者对已购食品的未来重复选择判断（Bedard & Kuhn, 2015; Motoki et al., 2023）。
[2274] 其次，本研究具体化了食品接受情境影响框架在购买后回购判断中的解释范围。Rozin和Tuorila（1993）指出，食品接受受到时间性与同时性情境的共同影响。本研究将该框架应用于购买后的回购判断，并分别考察目标食品与伴随沟通信息两个同时性情境方面，表明购买后的回购判断仍具有明确的情境依赖性。
[2275] 第三，本研究进一步说明，表情符号所承载的信息类型不能脱离其判断情境直接推断稳定的回购优势。食品表征型与情绪型表情符号分别提供食品对象信息与食品体验评价，但二者的相对回购效应会随目标食品所突出的评价属性以及伴随文字的沟通功能而变化。从信息整合理论看，总体判断由多种相关信息共同形成；结合食品接受情境影响框架，当前结果进一步表明，焦点视觉线索的回购效应需要结合目标食品及伴随沟通信息理解（Anderson, 1981, 2013; Booth & Conner, 1990; Rozin & Tuorila, 1993）。
[2276] 5.3 实践贡献
[2277] 本研究首先表明，餐饮企业在设计外卖小票时需要关注视觉元素是否能够与当前食品形成明确的意义联系。能够指向具体食品对象或食品享用体验的视觉信息更有可能关联积极的回购判断，因此小票视觉设计应优先考虑与订单食品具有明确对象或体验联系的符号，避免将表情符号简单作为装饰性元素使用。
[2278] 其次，食品类别应成为小票表情符号设计的重要依据。对于炸鸡等享乐属性较突出的食品，直接表征具体食品对象的视觉符号更有利于形成积极的回购判断；对于沙拉等健康属性较突出的食品，突出愉悦、满足和食品享用体验的情绪型表情符号表现出更高的相对优势。因此，餐饮企业可以依据不同食品突出的评价属性配置相应的视觉信息，减少跨品类统一使用同一表情符号设计所造成的信息错配。
[2279] 最后，小票中的文字与表情符号需要作为联合沟通信息加以设计。当文字突出消费体验和满足评价时，情绪型表情符号表现出更有利的回购结果，因此表达式文字可以优先与强调食品享用体验的情绪型表情符号结合。对于主要陈述食材、产品事实和属性信息的断言式文字，本研究没有发现两类表情符号之间存在可靠的回购差异，当前证据尚不足以支持某一表情符号类型在该文字情境下具有普遍优先性。
[2280] 5.4 研究限制与未来研究
[2281] 本研究测量的是购买完成、实际食用前形成的回购意愿。未来研究可结合实际品尝后的追踪测量与真实复购记录，检验小票中食品相关视觉信息在完整消费体验后的持续作用。
[2282] 本研究在特定食品与沟通情境中检验了食品相关视觉信息的作用，因此当前结果仍需在更广泛的食品类别与信息环境中加以检验。未来研究可扩展目标食品与沟通形式，并将具有直接行为导向的指令式沟通作为独立情境，以进一步界定当前情境效应的适用范围。
[2283] 本研究利用信息整合理论解释不同视觉信息在不同判断情境中的相对作用，但未直接测量信息评价与整合过程。未来研究可进一步测量消费者对不同信息的评价及其整合过程，以识别不同判断情境下视觉信息回购效应差异的心理基础。
