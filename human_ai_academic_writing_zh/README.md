# 使用说明

1. 新会话先读 `SKILL.md` + `MANIFEST.yaml`，执行 P08。
2. 新论文先做 M01–M04；若用户说“排兵布阵”，直接用 one-page template。
3. 找文献时先写 Citation Evidence Matrix，再执行 P04/P05。
4. PROCESS 相关先执行 P03，不凭 model number 记忆。
5. “逐句深度论证”强制执行 M11；“去 AI 味”执行 M12。
6. emoji corpus 只做错误/风格回归，不自动迁移其食品、emoji、Rozin、IIT 等具体内容到新项目。
7. `emoji_gold_manuscript.md` 是源文件最终可恢复正文；引用放置仍应按新版 P05 再审，不把 gold 当“每个细节永远正确”。
