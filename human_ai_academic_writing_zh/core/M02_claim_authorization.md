# M02 统计结果、实验设计与中文主张强度授权

核心顺序：**设计 → 测量 → 统计关系 → 可写主张。**

## Claim Ladder
- L1 描述性事实
- L2 统计关系
- L3 理论支持的解释
- L4 机制/参数主张（需要直接测量、操纵或专门识别）

## 授权矩阵
- 主效应：授权 X 对 Y 的比较/影响；不授权未测机制。
- 交互：授权 X 的效应随 W 条件变化；不授权 weight/value/processing。
- simple effect：只写真实 cell difference；不制造对称。
- p>.05：未观察到可靠差异；不等于相同/等价/无效。
- 中介：授权统计间接路径；不自动证明唯一/真实心理机制。
- 调节中介：必须看具体被调节路径和 index/相应 contrast；“一个显著一个不显著”不等于差异显著。
- 连续中介：支持理论规定的 serial indirect path；不自动证明真实心理时间顺序。
- manipulation check：只支持被检查构念被成功改变，不支持全部相邻心理维度。

## 设计权限
随机操纵 X 可支持相应 X→Y 因果解释；测量型 X 默认关系语言。M/Y 同时测量时，M→Y 的真实时间因果需要额外证据。

## 强制动词审计
证明、决定、驱动、激活、进入、重构、重加权、锚定、依赖等携带高 epistemic commitment，必须回查识别权限。

## 禁止
- interaction=机制
- interaction=weight change
- interaction=scale value change
- Study1 difference=w>0
- n.s.=equivalence
- DV 高=偏好/忠诚/行为（若未测）
- PROCESS model number=理论

## 默认安全语言
表明、显示、相对作用发生变化、间接路径、条件间接效应、当前结果未显示可靠差异。
