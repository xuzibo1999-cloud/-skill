# M01 研究事实冻结与写作启动协议

## 目的
正式写作前建立唯一 Ground Truth，防止写作阶段重新发明研究。

## 七张内部表
1. **Research Identity Card**：研究情境、判断阶段、对象、IV/DV/M/W、分析单位、RQ。
2. **Operational Variable Register**：理论名、实际变量名、levels、操纵/测量、刺激、允许的理论提升。
3. **Study Architecture Map**：每项 Study 的唯一问题、模型、结果、全文职责。
4. **Empirical Result Ledger**：描述性统计、主效应、交互、simple effects、间接效应、index、重要 n.s.。
5. **Measurement Boundary Register**：直接测量、刺激/理论属性、未测心理过程。
6. **Fact–Interpretation Separation**：F事实/T理论/E既有实证/I作者解释/S推测/W措辞。
7. **Project Freeze State**：FROZEN-3 实证、FROZEN-2 理论、FROZEN-1 结构、EDITABLE 语言。

## 变量三级
- Level A：实验操作/量表；
- Level B：研究构念；
- Level C：理论上位解释。

Title、H、Methods、Results 优先 A/B；Theory、Discussion、Contribution 可有控制地升到 C。

## 测量高风险词
感知、注意、激活、加工、编码、提取、诊断性、可及性、权重、标度值、心理表征、匹配感、依赖、重视。出现即问：测了吗？操纵了吗？设计识别了吗？

## Narrative Reconstruction 禁令
禁止：看到结果 → 建漂亮理论故事 → 逐渐把故事当成研究原本检验的事实。

经典回归案例：interaction → context dependence 可以；interaction → reweighting → Study2=weight → Study3=scale value → “完整覆盖理论参数”不可以。

## 启动流程
读取现有材料 → 提取明确事实 → 还原 X/Y/M/W → 还原统计结果（含 n.s.）→ 建变量层级 → 标未测构念 → 还原 Study progression → 冻结。

## 通过条件
- empirical consistency
- conceptual consistency
- authorization consistency
- status consistency

核心指令：**写作阶段不得重新发明研究。**
