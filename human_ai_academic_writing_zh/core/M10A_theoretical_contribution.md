# M10A 理论贡献识别与升维

理论贡献 = **既有知识边界与当前证据之间的明确 knowledge delta**。不是 Study 数量、H 数量或 theory 名称数量。

## Contribution Target Card
每项先写：目标 literature/theory、prior knowledge、missing boundary、current evidence、new knowledge、claim ceiling、not allowed。

## 六类合法增量
1. Scope Extension：理论/关系扩展到新的阶段、对象、载体或结果；
2. Boundary Specification：过去相对稳定的关系增加明确条件边界；
3. Process Clarification：支持新的中介解释路径；
4. Construct Differentiation：区分过去被混在一起的刺激/信息类型；
5. Theoretical Integration：两个理论真正形成非重叠功能组合；
6. Qualification/Constraint：限定既有简单命题的适用条件。

## Contribution–Evidence Matrix
每项贡献必须能追溯到 Introduction gap 和实际 Study result。一个结果可以支持不同抽象层，但不能把同一个 delta 拆成多项贡献换词重复。

## Theory Application ≠ Theory Contribution
“与理论一致”只说明兼容；把理论应用到新场景也不自动发展理论。真正贡献需要改变/扩展 scope、boundary、relation、construct differentiation 或 functional integration。

## 贡献写法
优先：prior state → current extension → evidence anchor → theoretical consequence。删除“重要、极大丰富、首次系统、完整闭环、打开黑箱”等自我评价。

## 最高安全抽象
从统计结果升到关系/边界/理论范围，不跨越到未测机制或参数。多个分别实施的实验可以共同支持上位结论，但不得写成“共同决定”。
