# M07A 主效应与单一中介逐路径推导

判断单位是“路径”，不是“变量”。文献证明变量重要，不等于证明变量之间存在目标关系。

## 主效应 X→Y
内部链：
1. 锁定 judgment target；
2. 确定 X1/X2 在当前设计中真正改变的最小信息/视觉属性；
3. 说明该属性为何与当前 Y 的判断相关；
4. 用能真正区分 X1/X2 的理论/领域实证产生方向；
5. 回到 actual X/Y 提 H。

总理论只有在确实能给方向时才承担方向。Existence Study 只建立 cue matters，不发明机制、参数、认知“入场资格”。

## 单一中介 X→M→Y
必须独立完成：
- Path a：为什么 X 改变 M；
- Path b：为什么 M 与当前 Y 有预期关系；
- Mediation qualification：为什么同一个 M 在当前对象中有资格连接 X 和 Y。

## Construct Fidelity
M 的理论定义、量表 items、正文名称必须一致。禁止 a-path 用 M 的一种含义，b-path 换成另一种近义构念。

## Evidence Levels
X→M 与 M→Y 分别标 Direct / Near-direct / Adjacent / Theory-only。核心路径不能全部依赖远距离 adjacent evidence 却写成确定机制。

## 禁止
- 定义 M 就推出 X→M；
- X→M + M→Y 两段拼接后机械“因此中介”；
- 未测 secondary mediator 插入链条；
- simultaneously measured M/Y 写成“首先—随后”；
- 数据显著后反向包装成事前核心机制。

## 遮住 H 测试
遮掉 H 后，前文是否基本唯一地推出当前方向？若不能，缺失链条或方向证据。
