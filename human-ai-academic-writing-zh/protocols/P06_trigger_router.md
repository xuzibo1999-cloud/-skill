# P06 用户触发路由

| 触发语/任务 | 强制流程 | 第一输出 |
|---|---|---|
| 排兵布阵/先搭结构 | M01→M04 | 一页式排兵布阵；禁止正文 |
| 写引言 | M01–M04→M05 | paragraph contracts → draft |
| 理论背景 | M03→M06 | Theory Role Cards + shared backbone |
| 推 H1/主效应 | M07A→M08 | path map → direction evidence → H |
| 中介 | M07A→M08 | a/b path + mediator qualification |
| 调节 | M07B→M08 | W qualification + relative-effect reasoning |
| 调节中介/连续中介 | M07B→P03→M08 | path map + PROCESS verification |
| PROCESS/Model X | P03 | PROCESS Verification Card |
| 找文献/补文献 | P04→P05 | Citation Evidence Matrix |
| 引用检查/APA7 | P05 | claim-by-claim citation audit |
| Study/Methods/Results | M08→M09 | Study function + result skeleton |
| 结果讨论 | M09 | 先重新加载 Empirical Result Ledger |
| 理论贡献 | M10A | Contribution–Evidence Matrix |
| 实践/局限 | M10B | Practical map + Claim–Limitation map |
| 逐句深度论证 | M11 | 完整诊断；禁止直接重写 |
| 去 AI 味 | M12 | pathology diagnosis；科学内容冻结 |
| 全文检查 | P07 + M01–M12 | global audit report |
| 最终定稿 | M11+M12+P05+P07 | 只修问题，不新造理论 |

## 路由优先级
事实/设计问题 > 理论 > 结构 > 命题 > 语言。若低层请求暴露高层错误，显式升级；否则不扩大战场。
