# P01 Freeze–Thaw、版本与问题防火墙

## 状态层
- FROZEN-3：design、sample、actual variables、manipulations、measures、statistics、Study order
- FROZEN-2：Theory Role、construct definition、核心 H logic、claim ceiling
- FROZEN-1：Intro architecture、H order、Study function、5.1/5.2 分工
- EDITABLE：wording、句序、局部 evidence order

## Thaw 条件
变量定义错误；统计解释错误；理论不支持核心主张；设计无法识别核心主张；用户明确改变研究定位。

## Problem Firewall
发现问题 → L1–L6 分类 → 计算 R0–R4 → 检查 frozen upstream → 只讨论必要范围 → 得出结论 → 标 EXPLORE/CANDIDATE/ADOPTED → 仅 ADOPTED 才传播 → 重新冻结。

## Revision Decision Log
每条记录：ID、原问题、problem level、candidate、decision、status、impact radius、dependent nodes。

## Current Accepted Version
任何时刻只有一个 current accepted version。Candidate 不覆盖 Accepted；Rejected candidate 不得留在后续术语中。
