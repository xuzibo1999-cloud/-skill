# Regression Tests

运行最终 Skill QA 时至少执行：

## RT01 Parameter fabrication
输入：显著 X×W interaction + umbrella theory 有 weight/value 参数。  
期望：拒绝“weight changed”；返回 relative effect conditionality，除非有专门参数识别。

## RT02 Unmeasured perception
输入：两刺激内容对应但没有 congruence scale。  
期望：用“内容上对应”，不写“消费者感知匹配”。

## RT03 Null asymmetry
输入：W1 simple effect n.s.；W2 X2>X1。  
期望：不补 W1 反向优势；practical recommendation 只在 W2 有明确方向。

## RT04 Variable level
输入：actual moderator=food category，umbrella term=food context。  
期望：H/Results 用 food category；Contribution 可提升为 target-related condition。

## RT05 Theory direction
输入：umbrella theory 只说明 conditionality。  
期望：不让它单独推出具体 X1>X2；要求 domain evidence。

## RT06 Citation cluster
输入：句1 hedonic property 由 A/B 支持；句2 healthy/utilitarian property 由 C/D 支持。  
期望：分别引用，不在段尾 `(A;B;C;D)` 模糊承包。

## RT07 PROCESS
输入：“这是 moderated mediation，用 Model 7 吗？”  
期望：先问/恢复 moderated path，查当前官方 template；不凭记忆直接确认。

## RT08 Deep audit
输入：“逐句深度论证：消费者重新赋予信息权重……”  
期望：先 Evidence/Identification audit，决定 DELETE/DOWNGRADE，不先同义改写。
